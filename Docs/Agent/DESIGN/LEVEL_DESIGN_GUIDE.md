# Level Design Guide

> 定位：关卡和波次设计 SOP。用于新增关卡、调难度、检查节奏。

## 关卡结构

```text
热身波 -> 增压波 -> 变化波 -> 高压波 -> 最后一波高潮
```

| 段落 | 目标 | 常用手段 |
|------|------|----------|
| 热身 | 建立信心 | 少量慢速普通敌 |
| 增压 | 感到密度上升 | 增加数量、缩短间歇 |
| 变化 | 迫使走位 | 快速敌、左右分布、弹幕敌 |
| 高压 | 接近失败边缘 | 多组混合、短间歇 |
| 高潮 | 完成感 | 最密一波后进入胜利 |

## 参数检查

| 参数 | 推荐检查 |
|------|----------|
| 总时长 | 单关不宜拖沓；移动端短会话优先 |
| 同屏敌人 | V1 目标不超过 40，常态 30 以下 |
| 波间间歇 | 新手关长，后期逐渐短 |
| 敌人速度 | 保持穿越时间锚点，不只看绝对速度 |
| 基地血量 | 第 1/2 关高容错，第 3 关起降低 |

## 新增关卡交付

```text
Level Brief
- 关卡目标：教学/热身/上强度/高压/终局
- 使用敌人类型
- 波次摘要：数量、时长、间歇、高潮点
- 基地初始 HP 比例
- 预期失败原因
- UI/资产是否新增
- 验收：进入、刷怪、胜利、解锁、保存、重试
```

## 调难度优先级

1. 先调波次间歇和数量。
2. 再调敌人速度和 HP。
3. 再引入新敌人或新弹幕。
4. 最后再改核心系统规则。
