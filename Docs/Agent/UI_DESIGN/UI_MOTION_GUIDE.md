# UI Motion Guide

> 定位：UI 动效语义和验收。

| 动效 | 目的 | 时长 | 规则 |
|------|------|------|------|
| 按钮按下 | 确认触摸 | 0.08-0.12s | 缩放到 95%，松开回弹 |
| 弹窗打开 | 聚焦 | 0.25-0.3s | 遮罩淡入，面板缩放 0.8 -> 1 |
| 弹窗关闭 | 结束 | 0.2s | 缩放 1 -> 0.9，淡出 |
| 血条预损 | 强化受伤 | 0.3-0.5s | 真实值先扣，白色预损延迟追赶 |
| 飘字 | 击杀/伤害反馈 | 0.8s | 上浮淡出，池化 |
| 波次提示 | 节奏变化 | 0.6s | 中央闪现，不阻挡操作 |
| 关卡解锁 | 进度奖励 | 0.4-0.8s | 锁打开、节点高亮 |
| 失败面板 | 降低挫败 | 0.3-0.5s | 从底部滑入，重试按钮突出 |

## 暂停语义

- 战斗暂停时，战斗逻辑冻结。
- FairyGUI Tween 若使用 Time.deltaTime 会随 TimeScale 冻结，这是预期。
- 需要暂停期间仍播放的 UI 动效必须显式说明 unscaled time。

## 验收

- 动效不影响点击热区。
- 动效结束后状态稳定，不残留 alpha/scale。
- 重试、退出、返回时所有循环动效停止。
