# UI Design Index

> 定位：UI/UX Agent 的设计知识路由。`SHOOTER_GAME/SG_UI_DESIGN.md` 是长文事实源，本目录提供可执行的设计系统、组件、屏幕和交接清单。

## 路由

| 我要做什么 | 读什么 |
|------------|--------|
| 确认 UI 风格和 token | `UI_DESIGN_SYSTEM.md` |
| 新增/修改组件 | `UI_COMPONENT_LIBRARY.md`, `skills/fairygui-tools/SKILL.md` |
| 新增/修改界面 | `SCREEN_CARDS.md`, `FAIRYGUI_HANDOFF_CHECKLIST.md` |
| 改动效 | `UI_MOTION_GUIDE.md` |
| 改文案 | `UI_COPY_GUIDE.md` |
| 进入代码实现 | `CONTEXT_PACKS/FairyGUI_UI.md`, `MODULE_CARDS/UISystem_FairyGUI.md` |
