# UI Copy Guide

> 定位：中文 UI 文案规则。

## 风格

- 短句、直接、偏鼓励。
- 按钮用动词：开始、继续、重试、确定、返回。
- 失败文案不责备玩家，强调“差一点”和“再来一次”。
- 资源未解锁提示说明条件，不写含糊的“不可用”。

## 常用文案

| 场景 | 文案 |
|------|------|
| Loading | 加载中... |
| LevelSelect 标题 | 选择关卡 |
| 未解锁 Toast | 通关前置关卡后解锁 |
| Pause 标题 | 游戏暂停 |
| 继续 | 继续游戏 |
| 退出确认 | 确定退出？本关进度不保存 |
| Victory | VICTORY |
| Defeat | DEFEAT |
| 重试 | 再试一次 |
| 失败鼓励 | 差一点！再来一次 |

## 禁止

- 不在界面里解释操作教程太长。
- 不使用依赖字体缺字的符号当核心信息。
- 不让按钮文字超过按钮宽度。
