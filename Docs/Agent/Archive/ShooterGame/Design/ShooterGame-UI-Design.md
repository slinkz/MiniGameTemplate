## 二、逐屏设计

---

### 2.1 启动加载（LoadingScreen）

**定位**：品牌露出 + 等待资源加载完毕

**布局**：
```
┌────────────────────────────┐
│                            │
│                            │
│                            │
│         [LOGO 图]          │
│        游戏名称文字          │
│                            │
│                            │
│                            │
│     ━━━━━━━━━━━━━━ 进度条   │
│         加载中...           │
│                            │
└────────────────────────────┘
```

**交互细节**：
- 进度条反映真实加载进度（资源 + 配置）
- 加载完毕后自动跳转选关界面，无需点击
- 若加载极快（<0.5s），仍保持最少 1 秒展示（品牌记忆）
- 背景色：深色（#1A1A2E），与游戏氛围一致

**元素清单**：
| 元素 | 规格 | 说明 |
|------|------|------|
| LOGO | 200×200 pt | 居中偏上 |
| 游戏名 | 36pt 粗体白色 | LOGO 下方 16pt 间距 |
| 进度条 | 宽 480pt 高 8pt 圆角 | 底部 20% 位置 |
| 加载文字 | 24pt 浅灰 | 进度条下方 |

### 2.2 选关界面（LevelSelectScreen）

**定位**：玩家的"大厅"，看到进度、选择目标

**布局**：
```
┌────────────────────────────┐
│  ◀ 标题：选择关卡            │  ← 顶部栏
│────────────────────────────│
│                            │
│        ┌───┐               │
│        │ 5 │ 🔒            │
│        └─┬─┘               │
│          │                  │
│        ┌─┴─┐               │
│        │ 4 │ 🔒            │
│        └─┬─┘               │
│          │                  │
│        ┌─┴─┐               │
│        │ 3 │ 🔒            │
│        └─┬─┘               │
│          │                  │
│        ┌─┴─┐               │
│        │ 2 │ ▶ (可进入)     │
│        └─┬─┘               │
│          │                  │
│        ┌─┴─┐               │
│        │ 1 │ ★ (已通关)     │
│        └───┘               │
│                            │
└────────────────────────────┘
```

**设计说明**：
- 关卡以**纵向航线**形式排列（从底部第1关到顶部第5关），暗示"向上攻克"的进度感
- 关卡之间用虚线/路径连接，已解锁路径亮起，未解锁路径暗淡
- 整个列表可以滚动（5 关足够一屏展示，但预留滚动能力）

**关卡节点三态**：

| 状态 | 视觉 | 交互 |
|------|------|------|
| 已通关 | 明亮底色 + ★ 标记 + 关卡编号 | 可点击（重玩） |
| 可进入 | 高亮脉冲动画 + ▶ 标记 + 关卡编号 | 可点击（进入战斗） |
| 未解锁 | 灰色 + 🔒 图标 | 不可点击，点击时轻微摇晃提示 |

**交互细节**：
- 点击可进入的关卡 → 0.3 秒缩放反馈 → 转场进入战斗
- 点击未解锁关卡 → 节点左右摇晃 0.3 秒 + 弱提示文字"通关前置关卡后解锁"（1.5 秒后消失）
- 选关界面没有"返回"按钮（这就是最顶层）
- 首次进入时，可进入关卡有**呼吸灯**效果引导点击

**转场动效**：
- 从加载页进入 → 整体淡入（0.3s ease-out）
- 从战斗结果返回 → 关卡列表从左侧滑入（0.3s）+ 新解锁关卡有"锁打开"动效

### 2.3 战斗 HUD（BattleHUD）

**定位**：战斗中的信息层，必须轻量、不干扰操控

**布局**：
```
┌────────────────────────────┐
│ [暂停⏸]          Wave 2/5  │  ← 顶部信息栏（安全区内）
│────────────────────────────│
│                            │
│                            │
│                            │
│     （战斗区域，无 UI）      │
│                            │
│                            │
│                            │
│                            │
│────────────────────────────│
│  ▉▉▉▉▉▉▉▉▉▉▉▉▓▓▓▓ 72%   │  ← 基地血条
│  ████████ 基地 ████████    │  ← 基地视觉区域
└────────────────────────────┘

虚拟摇杆（不可见，手指按下时出现）：
    按下 → 出现半透明圆形底座 + 摇杆头
    拖动 → 摇杆头跟随手指方向偏移
    松开 → 淡出消失
```

**元素详解**：

#### 顶部信息栏
| 元素 | 位置 | 规格 | 说明 |
|------|------|------|------|
| 暂停按钮 | 左上角 | 44×44 pt 热区 | 图标 ⏸，半透明白色 |
| 波次指示 | 右上角 | "Wave 2/5" 20pt | 告诉玩家进度，减少"还有多久"的焦虑 |

#### 基地血条
| 元素 | 位置 | 规格 | 说明 |
|------|------|------|------|
| 血条背景 | 基地区域上方 | 全屏宽 - 32pt 边距，高 12pt | 深灰底 |
| 血条填充 | 左对齐 | 随血量缩短 | 绿色(>50%)→黄色(30-50%)→红色(<30%) |
| 血量数字 | 血条右侧 | 18pt | "72%" 格式 |

#### 虚拟摇杆
| 元素 | 规格 | 说明 |
|------|------|------|
| 底座 | 直径 120pt 圆形 | 半透明白色(alpha=0.3)，手指按下时在按下位置出现 |
| 摇杆头 | 直径 50pt 圆形 | 半透明白色(alpha=0.6)，跟随手指方向偏移 |
| 最大偏移 | 60pt（半径） | 超过最大半径时钳制在边缘 |
| 响应区域 | 全屏 | 屏幕任意位置按下都可触发摇杆 |

**交互细节**：
- 暂停按钮点击 → 游戏暂停 → 弹出 PausePanel
- 血条扣减时有**流失动画**（先扣白色预损，再扣实际血量，0.3s 延迟）
- 血量 < 30%：血条脉冲闪烁 + 屏幕边缘红色暗角
- 波次切换时顶部短暂显示"Wave X"放大闪现（0.5s）
- HUD 所有元素**不阻挡触摸穿透**（暂停按钮除外）

**被撞反馈**（叠加在 HUD 上）：
- 全屏红色闪烁覆盖层（alpha 0→0.3→0，持续 0.2s）
- 血条震动（左右微抖 2 次）

```
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░│
│ ░░░┌──────────────────┐░░░│
│ ░░░│                  │░░░│
│ ░░░│    ⏸ 游戏暂停    │░░░│

│ ░░░│  └────────────┘  │░░░│
│ ░░░│                  │░░░│
│ ░░░│  ┌────────────┐  │░░░│
│ ░░░│  │  ✕ 退出关卡 │  │░░░│  ← 次按钮（小、暗色）

```

**交互细节**：
- 弹出动效：遮罩淡入 0.2s + 面板从中心缩放弹出（0.3s ease-out-back）
- [继续游戏] → 面板缩小消失 → 遮罩淡出 → 恢复战斗
- [退出关卡] → 确认弹窗（"确定退出？本关进度不保存"）→ [确定]返回选关 / [取消]关闭确认弹窗
- 遮罩点击 → 等同于点击"继续游戏"（快捷恢复）
- 暂停期间游戏逻辑完全冻结（时间缩放=0）

### 2.6 失败界面（DefeatPanel）

**定位**：挫败感最小化 + 强引导重试

**布局**：
```

│ ░░░│                  │░░░│
│ ░░░│    DEFEAT        │░░░│  ← 相对低调的失败字样
│ ░░░│                  │░░░│
│ ░░░│  消灭了 18/25 架 │░░░│  ← 进度提示（"差一点就赢了"）
│ ░░░│                  │░░░│
│ ░░░│  "再来一次！"     │░░░│  ← 鼓励文案
│ ░░░│                  │░░░│
│ ░░░│  ┌────────────┐  │░░░│
│ ░░░│  │ ↻ 再试一次  │  │░░░│  ← 主按钮（大、亮色、脉冲）
│ ░░░│  └────────────┘  │░░░│
│ ░░░│                  │░░░│
│ ░░░│     [返回选关]    │░░░│  ← 次按钮（文字链，弱化）
│ ░░░│                  │░░░│
│ ░░░└──────────────────┘░░░│
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░│
└────────────────────────────┘
```

**交互细节**：
- 弹出动效：屏幕渐暗（0.5s）→ 面板从底部滑入
- "再试一次" 按钮比 "返回选关" 视觉权重高 3 倍（大小 + 颜色 + 呼吸动效）
- [再试一次] → 面板滑出 → 重新初始化本关 → 战斗重新开始
- [返回选关] → 转场回选关界面
- 鼓励文案可随机："差一点！""你能行！""这次更近了！"
- 进度数字 "18/25" 暗示"你离胜利不远"——减轻挫败感

## 三、交互规范

### 3.1 按钮规范

| 类型 | 尺寸 | 圆角 | 反馈 |
|------|------|------|------|
| 主按钮 | 宽 280pt 高 56pt | 28pt 全圆角 | 按下缩小至 95% + 颜色加深，松开回弹 |
| 次按钮 | 宽 200pt 高 44pt | 22pt | 按下缩小至 95%，颜色变暗 |
| 文字链 | 自适应宽度 | - | 按下半透明，松开恢复 |
| 图标按钮 | 44×44 pt 热区（图标 28pt） | - | 按下缩小至 90%，松开回弹 |

**按钮颜色**：
- 主按钮：品牌色底（如 #4FC3F7 科技蓝）+ 白色文字
- 次按钮：深灰底（#3A3A4A）+ 浅灰文字
- 危险操作：暖红底（#EF5350）+ 白色文字

### 3.2 转场规范

| 转场 | 动效 | 时长 |
|------|------|------|
| 加载 → 选关 | 淡入淡出 | 0.3s |
| 选关 → 战斗 | 选中关卡缩放放大 → 全屏白闪 → 战斗场景淡入 | 0.5s |
| 战斗 → 选关（胜利后） | 面板淡出 → 画面缩小回到选关 | 0.4s |
| 战斗 → 选关（失败返回） | 面板滑出 → 淡入选关 | 0.3s |
| 重试 | 面板滑出 → 短暂黑屏 0.2s → 战斗重新开始 | 0.4s |

### 3.3 弹窗规范

- **遮罩**：黑色 alpha=0.6，点击遮罩行为视弹窗类型而定
- **弹出**：缩放 0.8→1.0 + 淡入，ease-out-back，0.3s
- **关闭**：缩放 1.0→0.9 + 淡出，ease-in，0.2s
- **层级**：遮罩 z=100，弹窗 z=101，确认二次弹窗 z=102

### 3.4 HUD 反馈规范

| 事件 | 视觉反馈 | 时长 |
|------|----------|------|
| 受到伤害 | 全屏红色闪烁层 alpha 0→0.3→0 | 0.2s |
| 击杀敌机 | 击杀位置飘出 "+10" 分数（向上漂浮淡出） | 0.8s |
| 波次切换 | "Wave X" 大字从中心放大淡出 | 0.6s |
| 血量 < 30% | 屏幕四周红色暗角常驻 + 血条脉冲 | 持续 |
| 无敌帧 | 飞机半透明闪烁（alpha 在 0.3-1.0 间切换，60ms 间隔） | 0.5s |

### 3.5 虚拟摇杆交互规范

```
状态机：
  [无触摸] ──按下──▶ [激活]
                      │
                    拖动 → 更新摇杆头位置 → 飞机移动
                      │
                    松开 ──▶ [消失]
                              │
                            飞机停止移动
                            摇杆淡出（0.15s）
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 死区半径 | 8pt | 偏移 < 8pt 时不响应移动（防误触） |
| 最大半径 | 60pt | 超过此距离摇杆头钳制在边缘，方向继续有效 |
| 出现动效 | 缩放 0→1，0.1s | 按下瞬间快速出现 |
| 消失动效 | 淡出 0.15s | 松开后短暂保留再消失 |
| 视觉层级 | z=50 | 在 HUD 之下，不遮挡信息 |
| 响应优先 | 最高 | 暂停按钮区域除外，全屏都是摇杆响应区 |

## 四、适配与安全区

### 4.1 竖屏适配策略

```
┌────────────────────────────┐
│▓▓▓▓▓▓ 状态栏/刘海 ▓▓▓▓▓▓▓│  ← 系统占用，不放交互元素
│────────────────────────────│
│                            │
│        安全区内容区          │  ← 所有 UI 元素在此区域内
│                            │
│────────────────────────────│
│▓▓▓▓▓ 底部安全区域 ▓▓▓▓▓▓▓│  ← 全面屏底部指示条区域
└────────────────────────────┘
```

**规则**：
- 顶部信息栏（暂停按钮、波次文字）下移至安全区顶部内
- 基地血条上移至安全区底部内
- 关卡列表内容区域在安全区内滚动
- 弹窗居中于安全区

### 4.2 横竖屏

- **仅支持竖屏**，锁定方向
- 微信小游戏 game.json 设置 `"deviceOrientation": "portrait"`
