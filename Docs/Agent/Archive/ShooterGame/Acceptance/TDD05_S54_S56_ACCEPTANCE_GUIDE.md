## 验收方法

1. 在编辑器中打开 `Battle` 场景
2. 使用 BattleDebugLauncher 配置测试关卡（选择已有关卡配置）
3. 确保装备 3 个主动技能 + 1~2 个被动技能
4. 运行 Play Mode，按上表逐项验收
5. 对于多解锁弹窗场景：使用调试命令 `DebugForceVictory` 在第 2 关通关来触发解锁
6. 失败面板的火力提示：确保有未解锁的技能（新开存档或重置进度）

### 快捷验收路径

```
1. D1~D6: 进入战斗 → 正常游玩 30s → 观察 HUD 各组件
2. E1~E5: 暂停/继续/重试/退出 → 依次验证
3. E6~E8: 通关 → 胜利面板
4. E9: 让基地被打死 → 失败面板
5. E10~E11: 通关有解锁条件的关 → 解锁弹窗
6. F1~F5: 战斗中观察视觉反馈
```
