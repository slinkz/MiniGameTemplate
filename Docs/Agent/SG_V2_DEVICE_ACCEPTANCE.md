## 第一部分：出战准备 + 核心战斗流程（~20 分钟）

### 准备工作

1. Unity 打开 **Boot** 场景 → Play Mode
2. Game 窗口分辨率设为 **750×1334**（竖屏）
3. 进入主菜单 → 射击游戏 → 选关界面
