# 十四、风险与未决项

| # | 风险 | 影响 | 缓解 |
|---|------|------|------|
| R1 | 敌方子弹 + 道具增加 Entity 数量 → 性能压力 | 掉帧 | 弹幕系统已优化（NativeArray），道具控制同屏数量 |
| R2 | 道具随机性导致平衡失控 | 某些组合太强/太弱 | 掉落表权重可调 + 关卡固定首掉保底 |
| R3 | BuffComponent 扩展字段多 → BuffSlot 内存增长 | 缓存不友好 | ✅ 已缓解（v1.4+v2.2）：DOT 拆为独立 DotSlot[16]，BuffSlot 保持精简 ~40 bytes；Buff 槽位扩至 16（16×40B=640B/Entity 可控） |
| R4 | 被动技能"子弹穿透"改变弹幕系统碰撞行为 | 需要弹幕层配合 | 在 BulletTypeSO 加 PierceCount 字段 |
| R5 | 敌弹视觉与我方弹区分不够 | 玩家混淆 | 严格颜色/大小/形状规范 |
| R6 | 策划工具（T1~T10）安排在 Sprint 5 → 数值 Playtest（Sprint 4）无工具辅助 | Playtest 效率低下，工时膨胀 | ✅ 已缓解（v1.5）：T5（ID 校验）提前到 Sprint 3 / T4（DPS 面板）提前到 Sprint 4 初期 |

|---|--------|------|------|
