## PK Round 1 — 攻方提问（技术文档工程师）

### DE-001 | 严重度 🔴高 | SkillType 枚举值与技能清单不一致——"EMP"从何而来？
**涉及文件/章节**：`SG_GDD_01` L82 SkillType enum + `SG_GDD_05` L579 约束表 EMP 字段组
**质疑**：SkillType enum 定义 6 种（Scatter/Homing/Laser/Overdrive/Shield/Shockwave），但约束表中突然出现 EMP 专属字段组（StunDuration/Radius）。V2 无 EMP 技能。开发者无法确定：是 V3 预留还是笔误？CustomEditor 是否需处理 EMP 分支？
**潜在风险**：SkillType enum 和 CustomEditor 实现时困惑——写 6 个还是 7 个？
**建议方向**：明确 EMP 是 V3 预留还是笔误。如果预留，在 enum 处标注 `// V3 预留`；如果笔误，从约束表移除。
**状态**：🟡 待回应

### DE-002 | 严重度 🔴高 | DOT 施加的完整触发链路缺失
**涉及文件/章节**：`SG_GDD_02` L301-307 DOT 清单 + `SG_GDD_04` L111-115 SOP
**质疑**：DOT 施加方式标注为"特殊子弹命中"（燃烧/中毒）和"激光技能附带"（电弧），但：(1) 无"特殊子弹"概念定义；(2) SkillConfigSO 激光字段组无 DotConfig 引用；(3) SOP 写"在需要施加 DOT 的地方引用"但没说明是哪个字段/组件。
**潜在风险**：开发者无法实现 DOT 施加逻辑，必须回去问设计师。
**建议方向**：补充 DOT 施加路径——可能在 BulletTypeSO 增加 `OnHitDotConfig`，或在 SkillConfigSO 激光字段组增加 `AttachedDot` 引用。
**状态**：🟡 待回应

### DE-003 | 严重度 🔴高 | 敌方 Debuff 施加机制完全未定义
**涉及文件/章节**：`SG_GDD_02` L199-204 敌方 Debuff 清单
**质疑**：文档定义 3 种 Debuff（减速/脆弱/致盲），标注"由玩家技能/特殊子弹施加"，但 V2 六种主动技能无一包含"施加 Debuff"效果，也无"特殊子弹"概念。开发者无法确定 V2 是否需要实现这些 Debuff。
**潜在风险**：开发者要么实现了无触发入口的 Debuff（浪费工时），要么跳过（功能缺失）。
**建议方向**：明确 Debuff 是 V2 实现还是 V3 预留。如果 V2，需补充施加机制。
**状态**：🟡 待回应

### DE-004 | 严重度 🟡中 | DPS 计算表中散射弹幕数值与参数不可推导
**涉及文件/章节**：`SG_GDD_03` L181 DPS 计算表 + `SG_GDD_01` L113 SK-P01 参数
**质疑**：散射 DPS = `5×10/0.3 ≈ 167/s`，但单发伤害"10"从未显式定义，且 CD=0.3s 应扣除后摇 0.1s → 有效周期 0.4s → DPS=125/s ≠ 167。开发者无法确认公式是否包含后摇。
**潜在风险**：数值验证时无法确认计算正确性，不清楚伤害配置入口。
**建议方向**：明确"我方子弹单发伤害"配置位置 + DPS 公式是否包含前摇/后摇。
**状态**：🟡 待回应
