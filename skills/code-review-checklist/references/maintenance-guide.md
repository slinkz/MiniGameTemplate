# 经验库维护规范 & 审查报告模板

> 归档自 SKILL.md，按需加载（日常审查无需阅读）。

## 经验库文件结构

```
references/
├── known-pitfalls.md              ← 活跃层（强制读取）
└── known-pitfalls-archive.md      ← 归档层（按需读取）
```

## 容量阈值

- **活跃层上限**：30 条（+ 不限数量 `[经典]` 条目）
- **触发蒸馏**：活跃层总条目 > 30 条

## 蒸馏规则（优先级排序）

1. **已固化到 CL 规则中的条目** → 活跃层留简短引用，原条目移归档层
2. **重复模式合并** → 合并为 1 条通用规则留活跃层，原始条目归档
3. **90 天未命中** → 降级归档
4. **`[经典]` 条目永不降级**

## 蒸馏操作步骤

1. 检查活跃层条目数量
2. 按优先级选出降级候选
3. 剪切到 `known-pitfalls-archive.md` 末尾
4. 活跃层原位留 `> 已归档 → PIT-0XX（归档原因）`
5. 更新条目计数注释

## 归档层额外格式

- 头部注释：`归档日期: YYYY-MM-DD`
- 归档原因：`已被 CL-X 覆盖` / `合并入 PIT-0YY` / `90 天未命中`

## 检查清单稳定度标记

- 某条 CL 规则连续 90 天零违规 → 标注 `[stable]`，审查时降低优先级
- 一旦再次违规 → 移除 `[stable]`

## 踩坑追加协议

新的编译错误或运行时 bug 被修复后，必须：
1. 在 `references/known-pitfalls.md` 追加 PIT 记录
2. 评估是否属于 CL-1~CL-10
3. 不属于任何类别 → 新增 CL-N
4. 属于但暴露新子模式 → 补充说明
